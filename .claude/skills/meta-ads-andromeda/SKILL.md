## Connaissances core

### Types de campagne
- **ABO** : budget fixe par adset — déconseillé depuis Andromeda
- **CBO** : budget au niveau campagne, réparti automatiquement selon performances — **méthode recommandée 2026**

### KPIs marché FR (références)
| KPI | Bon niveau |
|-----|-----------|
| CPA | 10-15€ pour panier moyen 40€ |
| CPM | 7-20€ selon niche |
| CPC | 0,20-0,80€ |
| CTR | ~2% |
| ROAS | > ROAS break-even (toujours) |

> **Priorité absolue : ROAS = métrique N°1. CPM/CPC/CTR = outils de diagnostic secondaires.**

### Structure CBO recommandée
- 1 campagne par produit/collection/event
- 1 adset par créative/concept/angle
- Toutes les variations dans le même adset
- Jamais 2x la même créative
- Budget 50-100€/j pour le marché FR

### Nombre de créatives max
- 50€/j → 15-20 créas max
- 100€/j → 30-35 créas max
- 300€/j → 75-100 créas max
*(Règle : budget/jour ÷ 3 = nombre max créas)*

## Diagnostic de campagne

### Quand analyser ?
- Toujours après **2-3 jours minimum**
- Toujours après **100-150€ dépensés minimum** sur tout le testing
- Prendre des décisions sur des **tranches de 3-7 jours minimum**

### Arbre de décision

```
Campagne CBO lancée → laisser 2-3 jours

├── ROAS > break-even (rentable) ?
│   ├── Légèrement rentable → laisser tourner, tester offres plus attractives
│   └── Bien rentable → scaler budget CBO + ajouter nouvelles créas
│
└── ROAS < break-even (pas rentable) ?
    ├── Stats pub trop chères ? → low budget, si pas d'amélioration : nouvelles créas
    ├── AOV trop bas ? → améliorer l'offre, augmenter valeur perçue
    └── Taux conv / ATC trop bas ? → simplifier page produit, vérifier marketing
```

---

## Scaling vertical CBO

- Augmenter **directement le budget** sur la campagne
- Scaler à **minuit** pour le lendemain (jamais en plein milieu d'une journée moyenne)
- Fréquence : tous les jours si scaling agressif / tous les 2-3 jours pour sécurité

### Si ROAS baisse après scaling
| Situation | Action |
|-----------|--------|
| Baisse mais toujours rentable | Normal (variance) → observer 48h |
| Rentable mais proche break-even | Ne rien faire 2-3j + ajouter 5-10 créas |
| Pas rentable | Stopper le scaling + baisser budget + 5-10 nouvelles créas |

## Créatives

### Formats
- Feed : **4:5** (1080×1350px)
- Story : **9:16** (1920×1080px) avec 250px safe zone haut/bas

### Concepts image qui fonctionnent
Focus produit · Memes · Avant/Après · Post-it · Note iPhone · Comparaison (us vs them) ·
Problème/Solution · Bullet points · Review · Story réponse question · Presse (faux magazine)

> **Les créatives image simples fonctionnent le mieux.**

### Règles de diversité
- Mix images + vidéo
- Angles différents (pas 20 UGC avec juste le hook qui change)
- Changer **50%+ de la créa** pour éviter le score de similarité Meta
- Diversité : UGC, natif, focus produit, angle différent

### Adcopy
- Privilégier un adcopy **long** (tester aussi une version courte)
- Suivre la structure **AIDA** (Attention → Intérêt → Désir → Action)
- Mettre les **bénéfices** en avant, jamais les caractéristiques
- Ne pas être trop agressif sur les promesses

## Funnel & Niveaux de Conscience

Pour le détail complet des blocs de script par niveau, référer à :
→ `references/funnel-awareness.md`

### Les 5 niveaux de conscience (Eugène Schwartz)

| Niveau | État du prospect | Exemple concret |
|--------|-----------------|-----------------|
| **Unaware** | Inconscient du problème | "Ma femme ne me regarde plus comme avant" |
| **Problem Aware** | Conscient du problème | "On a perdu l'attirance l'un pour l'autre" |
| **Solution Aware** | Conscient de la solution | "Se muscler sérieusement" |
| **Product Aware** | Conscient du produit | "Programme de Nick vs programme de Will" |
| **Most Aware** | Très conscient | "Le programme de Nick est à -50%" |

### Pourquoi c'est critique pour les créatives

- Les créatives qui s'adressent aux **Unaware ont 20x plus d'impact** que celles en bottom of funnel
- Elles génèrent des ventes ET font entrer de nouvelles audiences dans le funnel
- L'acte d'achat n'est **pas linéaire** : la majorité des clients voient plusieurs pubs avant d'acheter
- Sans créatives couvrant tous les niveaux → des audiences restent "bloquées" dans le funnel

### Règle de script selon le niveau de conscience

- **Plus le prospect est inconscient → plus le script est long et éducatif**
- Produits santé : souvent VSL (>10 min) + LP ou advertorial pour éduquer davantage
- **Unaware** : call out symptômes → éduquer → diagnostiquer → pain point → solution → social proof + objections → CTA
- **Problem Aware** : diagnostiquer → pain point → solution → social proof + objections → CTA
- **Solution Aware** : solution → social proof + objections → CTA

### Comment construire un funnel performant

- Multiplier les formats : vidéo (UGC, podcast, fondateur, réponses aux objections), statiques, comparaisons
- Adapter le copy à chaque niveau d'awareness
- Plus tu produis de créatives diversifiées, plus tu fais avancer les prospects dans le funnel
- Objectif : couvrir **tous** les niveaux avec des messages différents

## Playbooks

Résumé rapide :
- **CPA élevé + ATC faible** → problème de site/offre/cohérence créa-page

- **CPM extrêmement cher** → incohérence créa/persona ou mauvais site/offre

## Les 3 erreurs fondamentales à rappeler si pertinent

1. **Mauvais choix produit** → favoriser produits problème-solution vs fashion/gadget
2. **Mauvais marketing** → bénéfices avant caractéristiques, promesse dès le début
3. **Mentalité court terme** → ne jamais couper après 1 jour, penser business long terme

---

## Règles de réponse

1. Toujours commencer par **identifier le vrai problème** avant de donner des solutions
2. Si l'utilisateur donne des stats → diagnostiquer avec l'arbre de décision
3. Si créative fatigue → recommander de nouvelles créas ET de la diversité d'angles
4. Rappeler que **si le ROAS global est bon, une créa à 1,5 ROAS peut rester** (rôle awareness dans l'écosystème)
5. Ne jamais recommander de couper une campagne après seulement 1 jour
