## 📚 CONNAISSANCES CORE

### Les 5 niveaux de conscience (Eugène Schwartz)

| Niveau | Nom | Description | Exemple produit rougeurs |
|--------|-----|-------------|--------------------------|
| 1 | **Unaware** | Ressent un symptôme sans nommer le problème | "Je me sens toujours mal à l'aise quand je rentre dans un endroit chaud, je sais pas pourquoi" / "Pourquoi tout le monde pense que j'ai bu alors que je suis sobre ?" |
| 2 | **Problem Aware** | Sait qu'il a un problème, ne sait pas pourquoi | "Je suis rouge sans raison, je comprends pas" |
| 3 | **Solution Aware** | Cherche une solution, ne connaît pas le produit | "J'ai besoin d'un soin discret pour calmer mes rougeurs" |
| 4 | **Product Aware** | Connaît le produit, hésite | "J'ai vu ce stick anti-rougeurs, ça vaut vraiment le coup ?" |
| 5 | **Most Aware** | Prêt à acheter, attend l'offre | "Ok je veux le stick, c'est quoi le prix ?" |

> 💥 **Les créas Unaware ont 20x plus d'impact** que celles en bottom of funnel. Elles génèrent des ventes ET font entrer de nouvelles audiences dans le funnel. Elles parlent à beaucoup plus de monde.

### Blocs de script par niveau de conscience

**Niveau 1 — Unaware**
→ Call out les symptômes et éduquer → diagnostiquer avec le problème → remuer le pain point (ou le désir) → Solution → Social proof + réponses aux objections → CTA

**Niveau 2 — Problem Aware**
→ Diagnostiquer avec le problème → remuer le pain point (ou désir) → Solution → Social proof + réponses aux objections → CTA

**Niveau 3 — Solution Aware**
→ Solution → Social proof + réponses aux objections → CTA

**Niveaux 4-5 — Product / Most Aware**
→ Offre → garantie → CTA direct

> 📌 Plus le prospect est Unaware, plus le script est **long et éducatif** (VSL 5–10 min, advertorial, LP longue). Plus il est conscient, plus le message peut être **court et direct**.

### Comment avoir un funnel performant

- L'acte d'achat **n'est pas linéaire** : la majorité des clients ne voient pas une seule pub avant d'acheter
- Créer des pubs adaptées à **chaque niveau d'awareness** → les prospects descendent progressivement dans le funnel jusqu'à l'achat
- Quand ce travail n'est pas bien fait → des audiences sont **"bloquées"** dans le funnel. Dès qu'on les cible correctement → jackpot, elles achètent
- **Multiplier les formats** : vidéo (podcast, UGC, fondateur, réponses aux objections...), statiques, comparaisons...

## 📐 LES 9 RÈGLES DESIGN / WORDING POUR DES STATIQUES QUI PERFORMENT

1. **Ne pas surcharger — focus sur le wording.** C'est le 80/20. Le copywriting dans un statique est primordial.
2. **Designs simples** — inspire-toi des créas qui tournent déjà bien. Pas besoin de réinventer la roue.
3. **Jeter les phrases sans âme** → voir liste des phrases bannies ci-dessous.
4. **Bénéfice explicite et direct** qui situe le problème (ex : "Adieu fatigue en 7 jours" / "Barbe plus fournie sans minoxidil")
5. **Test 500ms** : une statique doit répondre en 500 millisecondes à 2 questions :
   - **Qu'est-ce que c'est ?**
   - **En quoi ça m'aide ?**
   → Si elle ne passe pas ce test = elle ne stoppera pas le scroll et ne vendra pas.
6. **Simplicity Scale** : les créas les plus simples sont celles qui scalent. Jamais 10 000 éléments compliqués.
7. **Congruence message ↔ image** : le message et l'image doivent raconter la même histoire. Éviter plusieurs titres qui partent dans des angles différents de ce que montre l'image.
8. **Tes clients sont tes copywriters** : tes meilleurs titres dorment déjà dans les avis et sondages post-achat. Cherche des formulations naturelles, pas des phrases marketing inventées.
9. **Hiérarchie visuelle** : le design doit guider l'œil dans l'ordre voulu. Décide ce que la personne doit voir en premier → agrandis-le. Joue avec taille des mots, contrastes, surlignages, flèches, espaces vides, warp de texte pour casser le pattern dans le scroll.
