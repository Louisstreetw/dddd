## ⚡ PROCÉDURE OBLIGATOIRE POUR CHAQUE DEMANDE DE COPY

1. **LIRE** PSYCHOLOGIE_COPY.md + STATIQUES_QUI_SCALE.md (si pas déjà fait dans ce thread)

2. **IDENTIFIER** :
   - Niveau d'**awareness** ciblé (Unaware → Most Aware)
   - Niveau de **sophistication** du marché (par défaut N2-N3 pour stick anti-rougeurs FR)
   - Format demandé (statique / vidéo / VSL / autre)
   - Audience : **cold** (acquisition) ou **warm** (retargeting) — défaut cold si pas précisé

3. **PUISER** dans les 3 transcriptions Julien (le persona qui parle face caméra) avant d'inventer une seule phrase

4. **APPLIQUER** les 5 leviers émotionnels (au moins 1 par copy) :
   - Encourager les rêves / Justifier les échecs / Apaiser les peurs / Confirmer les soupçons / Blâmer un ennemi

5. **VÉRIFIER la congruence interne** : Hook + Body + CTA = même niveau d'awareness

6. **APPLIQUER Hormozi** sur chaque value prop : ↑ Dream / ↑ Probabilité / ↓ Temps / ↓ Effort

7. **TESTER à voix haute** : ça sonne pub ou humain ?

8. **MONTRER la transformation**, pas le produit

9. **SI statique** : appliquer en plus les 9 règles Adrate + le test 500ms ("Qu'est-ce que c'est ?" + "En quoi ça m'aide ?")

10. **TOUJOURS proposer plusieurs angles différents** (pas variations du même)

```

👥 AUDIENCE : Cold / Warm

🪝 HOOK 1 (Levier : [rêve/échec/peur/soupçon/ennemi]) :
"[texte]"
→ Pourquoi ça marche : [explication ancrée sur verbatim ou framework]
→ Test voix haute : ✅/❌

🪝 HOOK 2 (Levier : [...]) :
[...]

[etc. — 5 minimum, angles VRAIMENT différents]

💡 Hook recommandé en priorité : N°[X] parce que [...]
💎 Golden Nugget brut à tester aussi : "[phrase verbatim]"
```

  • [...]
  • [...]
  • [...]

  - Qu'est-ce que c'est ? → [réponse en <1 sec]
