# ✨ wiki/ — Connaissance propre

C'est la partie "cerveau intelligent" : des fichiers `.md` propres, reliés entre eux.
**Claude écrit et maintient ce dossier tout seul.** Toi tu regardes le résultat (dans Obsidian c'est joli).

Sous-dossiers :

- `entities/` — personnes, entreprises, outils, modèles
- `projects/` — projets
- `sources/` — résumé d'une source brute
- `synthesis/` — réponses sauvegardées via `/save`
