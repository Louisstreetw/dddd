# 🧠 Index du Second Cerveau de Jarvis

Point d'entrée du cerveau. Les grandes zones de connaissance apparaissent ici au
fur et à mesure qu'on les remplit.

## Zones de connaissance

_(vide pour l'instant — se remplit automatiquement quand tu fais `/ingest`)_

- **Concepts** → `wiki/concepts/`
- **Entités** (personnes, outils, boîtes) → `wiki/entities/`
- **Projets** → `wiki/projects/`
- **Sources** (résumés de docs bruts) → `wiki/sources/`
- **Synthèses** (réponses sauvegardées) → `wiki/synthesis/`

## Comment ça marche

1. Tu déposes un truc dans `raw/` (PDF, article, note…).
2. Tu tapes `/ingest` → le cerveau range et relie tout.
3. Tu tapes `/query "ta question"` → il répond depuis le cerveau.
4. Tu ouvres le tout dans Obsidian pour voir le graphe des connexions.
