# 📥 raw/ — Sources brutes

Dépose ICI tout ce que tu veux ajouter au cerveau, en vrac :
- PDF, articles, transcriptions de vidéos, notes, captures d'écran web…

Règles :
- Claude **lit** ces fichiers mais n'y **touche jamais**.
- Nomme tes fichiers simplement : `article-1.md`, pas `Mon article génial (2).pdf`.
- Une fois déposé, tape `/ingest` pour que Claude range tout dans le `wiki/`.
